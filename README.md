# پروژه آزمایشگاه هوش مصنوعی گروه ۵
## بخش پاک‌سازی داده‌ها و ارزیابی (Data & Evaluation)

### معرفی پروژه
این مخزن شامل بخش پاک‌سازی داده‌ها و ارزیابی پروژه آزمایشگاه هوش مصنوعی گروه ۵ است. هدف پروژه، توسعه یک سیستم مسیریابی هوشمند شهری برای شهر شیراز با استفاده از الگوریتم‌های هوش مصنوعی و گراف است.

### مسئولیت من در پروژه
**نام:** ناصر شاهین  
**بخش فعالیت:** پاک‌سازی داده‌ها و ارزیابی (Data & Evaluation)

وظایف این بخش عبارت‌اند از:

- پاک‌سازی و اعتبارسنجی اطلاعات شبکه معابر
- بررسی صحت مختصات جغرافیایی گره‌ها
- بررسی طول و وزن یال‌های شبکه
- شناسایی گره‌های بدون اتصال
- بررسی اتصال‌پذیری شبکه و مؤلفه‌های گراف
- شبیه‌سازی موانع و مسدود شدن خیابان‌ها
- افزایش هزینه عبور از مسیرهای مشخص
- طراحی سناریوهای آزمایشی برای ارزیابی سیستم مسیریابی
- تهیه گزارش کیفیت داده‌ها

### ساختار داده‌های گراف

در این پروژه از گراف جهت‌دار و وزن‌دار `MultiDiGraph` استفاده می‌شود.

- `x`: طول جغرافیایی (Longitude)
- `y`: عرض جغرافیایی (Latitude)
- `length`: طول مسیر برحسب متر
- `weight`: وزن مسیر برای محاسبات مسیریابی

### سناریوهای آزمایشی

برای بررسی عملکرد سیستم، سه سناریوی اصلی در نظر گرفته شده است:

1. مسدود شدن یک خیابان
2. مسدود شدن چند خیابان به‌صورت هم‌زمان
3. افزایش هزینه عبور از خیابان‌های مشخص

آزمایش‌های اولیه با استفاده از شبکه مصنوعی ۸×۸ انجام‌پذیر هستند. این شبکه صرفاً برای آزمایش است و نمایش‌دهنده خیابان‌های واقعی شیراز نیست.

### وضعیت پروژه

پیاده‌سازی اولیه فایل‌های مربوط به پاک‌سازی داده‌ها، تولید موانع، طراحی سناریوهای آزمایشی و مستندسازی انجام شده است. اجرای کدها، رفع خطاها و ثبت نتایج نهایی ارزیابی در مراحل بعدی انجام خواهد شد.
